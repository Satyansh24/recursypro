Full-Stack MERN Architecture • Vercel Deployment Guide

Deploy Frontend & Backend on Vercel + Link MongoDB Atlas

Follow these exact steps to run locally in VS Code and deploy both folders (`backend/` and `frontend/`) to Vercel.

1. Local VS Code Testing

Open terminal in backend/ folder:
npm install
npm start
Put your MongoDB Atlas URI in backend/.env. Then open frontend/index.html with Live Server.

2. Deploy Backend to Vercel

Push project to GitHub. In Vercel, import repo, set Root Directory to backend, and add Environment Variables: MONGO_URI and JWT_SECRET. Copy your live backend URL.

3. Link Frontend & Deploy

Open frontend/app.js (Line 6) and replace http://localhost:5000/api with your Vercel Backend URL (e.g. https://recursy-api.vercel.app/api). Deploy frontend folder to Vercel!
